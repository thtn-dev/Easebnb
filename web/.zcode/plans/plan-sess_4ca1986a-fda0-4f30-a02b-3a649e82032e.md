# Implement /api/v1/account — tái dùng 100% auth infrastructure

## Contract đã xác nhận từ `open-api-v1.json` (khớp spec task)
- `GET/PUT /api/v1/account/me` → `ApiResponseOfUserInfo` (`{data: UserInfo|null, success, message}`), security Bearer. `UpdateProfileRequest = {email: string|null, phoneNumber: string|null}` (cả 2 field luôn present, nullable).
- `POST change-password` (`{currentPassword,newPassword,confirmNewPassword}` — auth) và 4 endpoint public `confirm-email` (`{userId: uuid, token}`), `resend-email-confirmation` (`{email}`), `forgot-password` (`{email}`), `reset-password` (`{email,token,newPassword,confirmNewPassword}`) → `ApiResponse {success, message}`.
- **Bỏ qua** `change-picture-profile` (không upload UI, không TODO ảnh hưởng).

## Tái dùng (không tạo mới)
API client (`lib/api/client.ts` + Authorization header + 401→refresh→retry), auth-bridge, auth store, AuthGuard/GuestGuard, `apiResponseSchema`/`userInfoSchema` từ `features/auth/schemas` (không duplicate UserInfo/ApiResponse), zod forms, `collectFieldErrors`, FieldError/Alert/Spinner patterns.

## Files

**Sửa duy nhất infra (tối thiểu, backward compatible):** `stores/auth-store.ts` — thêm action `setUser(user)` cập nhật `auth.user` + re-persist session (giữ tokens/rememberMe). Mục tiêu §18: `auth.user` luôn là user hiện tại.

**`src/features/account/schemas.ts`** — zod: `updateProfileRequestSchema` (email nullable + email format khi không null, phoneNumber nullable), `changePasswordRequestSchema` (+refine match), `confirmEmailRequestSchema`, `resendEmailConfirmation`/`forgotPasswordRequestSchema` (email format), `resetPasswordRequestSchema` (+refine match), `userInfoResponseSchema` (envelope reuse `userInfoSchema` từ auth). Types qua `z.infer`.

**`src/features/account/api.ts`** — 7 service functions dùng `api` client hiện có: `getCurrentUser()`, `updateProfile()` (GET/PUT — authenticated, header tự động), `changePassword()` (auth), `confirmEmail()`, `resendEmailConfirmation()`, `forgotPassword()`, `resetPassword()` (4 cái cuối `skipAuth: true` — public, không gửi Authorization, không trigger auto-refresh). Parse envelope, `success === false` → ApiError với message; message-only endpoints trả về `message` để UI hiển thị.

**`src/features/account/session.ts`** — state sync: `refreshCurrentUser()` (GET me → setUser), `updateProfile()` (PUT → setUser từ response data), `confirmEmail()` (confirm → nếu đang authenticated thì refreshCurrentUser để cập nhật emailConfirmed; swallow error nếu anonymous), các action còn lại wrap api.

**Components (`src/features/account/components/`)** — theo pattern form auth hiện có (useState + zod + FieldError + Alert + Spinner + disable submit):
- `account-overview.tsx` —UserInfo + actions: Edit profile (/account/profile), Change password (/account/security), Resend confirmation (hiện khi `!emailConfirmed`, loading + message), Logout (reuse `logout()`).
- `profile-form.tsx` — email/phone prefill từ `auth.user`, empty → null khi submit, PUT thành công → state update + success message.
- `change-password-form.tsx` — 3 field + match validation; success → message + reset form, KHÔNG logout.
- `confirm-email-panel.tsx` — client component nhận userId/token props; thiếu → error; đủ → auto-call một lần trên mount; loading/success/error states.
- `forgot-password-form.tsx` / `reset-password-form.tsx` — theo spec §8-9 (reset prefill email+token từ query nếu có, success → link /login).

**Pages (6 routes):**
- `/account`, `/account/profile`, `/account/security` — protected (AuthGuard từng page, không wrap `/account/layout` vì `/account/confirm-email` phải public).
- `/account/confirm-email` — public; Server Component `await searchParams` (Next 16: searchParams là Promise) → truyền props cho client panel.
- `/forgot-password`, `/reset-password` — public; reset-password page `await searchParams` prefill.

**Sửa nhỏ:** login-form thêm link "Forgot password?" → `/forgot-password`.
