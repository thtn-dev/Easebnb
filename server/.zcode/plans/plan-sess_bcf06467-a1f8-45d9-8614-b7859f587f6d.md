## Test inventory (~42 tests, 4 files)

### 1. `Organizations/OrganizationEndpointTests.cs` (~18)
- **Create**: authenticated → 200 envelope + DB asserts (org Active, `owner_user_id` = creator, membership Owner — invariant Option A qua HTTP); slug null → auto-gen từ tên tiếng Việt; 401 không token; 400 slug format sai (ValidationProblem, key PascalCase `Slug`); 409 slug trùng; 400 thiếu name.
- **Get**: by id member → 200; by id không phải member → 403; id lạ → 404; by slug (case khác) → 200.
- **My organizations**: chỉ org của user + exclude org người khác + pagination metadata; page=0 → 400.
- **Update**: owner → 200 persist xuống DB; slug bị trùng → 409; member → 403; org archived → 409.
- **Archive**: owner → 204 + DB Status=Archived + update tiếp theo → 409; admin → 403.

### 2. `Organizations/OrganizationLogoEndpointTests.cs` (~4)
- Admin upload JPEG hợp lệ (multipart) → 200, `logoKey` persist, mock verify `PutAsync` bucket `easebnb-organizations` + key prefix `organizations/{id}/logo/`, old key bị `DeleteAsync`.
- File không phải ảnh (magic bytes sai) → 400.
- Member → 403.
- Không token → 401.
- *Note rate limiter*: "file-upload" là fixed window 10 req/min global — giữ ≤4 upload tests; nếu lộ 429 thì post-configure NoLimiter policy trong fixture (ghi chú mitigation).

### 3. `Organizations/OrganizationMemberEndpointTests.cs` (~17)
- **GetMembers**: member bất kỳ → 200 list enriched từ `registered_users` (DisplayName/Email/Role/JoinedAt), user thiếu projection → field null; pagination metadata; không phải member → 403.
- **AddMember**: admin + target có projection → 200 + response enriched; target không tồn tại trong registered_users → 404; duplicate → 409; role "Owner" → 409; role sai → 400; actor là Member → 403.
- **ChangeRole**: owner transfer ownership → 200 + **DB asserts đủ 3** (target=Owner, owner cũ=Admin, `owner_user_id` đổi); admin promote Member→Manager → 200; admin grant Owner → 403; đổi role của owner hiện tại → 409; org archived → 409.
- **RemoveMember**: owner remove member → 204 + list giảm; target là owner → 409; admin remove admin → 403.

### 4. `IntegrationEvents/UserRegisteredProjectionTests.cs` (~2, flagship)
- **E2E pipeline**: register user qua `/api/v1/auth/register` → `WaitForRegisteredUserAsync` (poll ≤15s) → assert row đúng email/username → **AddMember user đó thành công 200** → GetMembers hiển thị đúng (chứng minh full chain: domain event → MassTransit outbox → in-memory transport → consumer + inbox → projection → business rule dùng được).
- GetMembers hiển thị member vừa add qua projection thật (không seed tay).
